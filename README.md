# Time Material

A desktop day board for finding when working hours overlap.

Cities sit in rows on one shared day. Drag the meeting cut and each row shows that instant in local time. Hours everyone can work are marked. Google Calendar busy time, and Zoom calls the events already point at, lie on the same day when the calendar can be read. If it cannot, the page says so and does not guess.

Work hours default to 09:00–17:00 on weekdays. Change them per city. The first city is the axis the day is ruled from.
